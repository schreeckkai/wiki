## Nutzung als Obsidian-Vault

Dieses Repo ist direkt als Obsidian-Vault nutzbar:
1. Repo klonen oder als Ordner öffnen
2. In Obsidian: `Datei → Vault öffnen` → diesen Ordner wählen
3. Querverweise per `[[...]]` erstellen
4. Graph-View zeigt Verbindungen zwischen Themen

## Content pro Themenfeld

Jedes Themenfeld-Verzeichnis kann enthalten:
- `Definitionen.md` – formale Begriffe
- `Formeln.md` – relevante Formelsammlung
- `Merksaetze.md` – Besonderheiten, Fallunterscheidungen
- `Aufgaben/` – typische Aufgaben mit Lösungswegen
- `Notizen.md` – freie Anmerkungen
