# E1/E2 – Grundlagen der Analysis

Themenfelder der Einführungsphase (1. Halbjahr).

## Themenübersicht
- E.1 Funktionen und ihre Darstellung
- E.2 Einführung des Ableitungsbegriffs
- E.3 Anwendungen des Ableitungsbegriffs
- E.4 Exponentialfunktionen
- E.5 Trigonometrische Funktionen
- E.6 Weitere Verfahren zum Lösen von Gleichungen *(optional)*
- E.7 Folgen und Reihen *(optional)*

## Kompetenzanforderungen
- Erarbeiten grundlegender Begriffe und Eigenschaften anhand von ganzrationalen Funktionen
- Definitionsmenge, Wertemenge, Wertetabelle, grafische Darstellung
- Symmetrie von Funktionsgraphen
- Verhalten für große Argumente (mit Limes-Schreibweise)
- Erkennen der Verschiebung und Streckung von Funktionsgraphen
- Bestimmen besonderer Punkte (Achsenschnittpunkte, Schnittpunkte)
- Modellieren von Realsituationen durch Funktionsklassen
